Vapi Setup Instructions

1. System Prompt
- Open `vapi/system_prompt.txt` and copy its entire contents into your Vapi assistant's System Prompt / Instructions field. This enforces the authentication guardrails and behavior.

2. Tools
- Use the JSON in `vapi/tool_definitions_for_vapi.json` to create/register tools in the Vapi dashboard. Each function definition includes a `webhook` field with the public endpoint generated by the tunnel.
- For each tool, set the webhook/endpoint to the `webhook` value and ensure the HTTP method is POST and `Content-Type: application/json`.

3. Webhook URL
- The mock server webhook endpoint is:

  https://short-weeks-turn.loca.lt/webhook

- Use this exact URL when configuring the tool destinations in Vapi.

4. Voice Pipeline (recommended)
- STT: Deepgram (or equivalent)
- LLM: GPT-4o / compatible conversational model
- TTS: ElevenLabs or Cartesia

5. Testing
- Start a call in the Vapi dashboard and follow the flow. Use test verification code `1234` for `account_id` `ACC-88392` (per repo test data).

6. Notes
- The tunnel will expire when the terminal running `localtunnel` is closed. Keep that terminal open while testing.
- If you prefer ngrok, install it and run `ngrok http 3000` and replace the webhook URL accordingly.
